# 게시물 조회 API 명세

## 전체 게시물 조회

모든 게시물을 조회합니다. 정렬 순서는 보장하지 않습니다.

### 요청

```http
GET /posts
```

### 성공 응답

- 상태 코드: `200 OK`
- Content-Type: `application/json`
- 응답 본문: 모든 게시물을 담은 JSON 배열

각 게시물은 아래 두 필드만 포함합니다.

| 필드      | 타입   | 설명                 |
| --------- | ------ | -------------------- |
| `id`      | string | 게시물의 고유 식별자 |
| `content` | string | 게시물 본문          |

```json
[
  {
    "id": "1",
    "content": "첫 번째 게시물입니다."
  },
  {
    "id": "2",
    "content": "두 번째 게시물입니다."
  }
]
```

게시물이 없으면 `200 OK`와 빈 배열을 반환합니다.

```json
[]
```
